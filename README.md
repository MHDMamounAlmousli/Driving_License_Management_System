# Driving_License_Management_System
Project Description: A driver’s license and vehicle management application designed using a 3-tier architecture.

Technologies Used: C#, WinForms, .NET Framework, SQL Server, ADO.NET.

Key Features: Applicant management, examinations (vision, written, and practical driving tests), issuance and renewal of licenses, and management of fines and penalties.

How to Run: Execute the DVLD.sql script in SQL Server and connecte the application to the database. Open the solution in Visual Studio and run the project.
